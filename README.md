# Soil Data Analysis 🌱📊

An Excel-based **Karnataka Soil Nutrient Analysis Dashboard** created to analyze soil characteristics and nutrient levels across different districts of Karnataka.

### 📌 Project Features
- Analysis of **31 Karnataka districts**
- Soil type analysis
- pH and average pH analysis
- Nitrogen level analysis
- Potassium level analysis
- District-wise soil data analysis
- Dashboard with key soil nutrient KPIs
- Interactive and visual presentation of soil-related data

### 📊 Dashboard KPIs
- Total Districts: **31**
- Average pH: **6.84**
- Average Nitrogen: **253.9 kg/ha**
- Average Potassium: **12.4 kg/ha**

### 🛠️ Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Excel Dashboard
- Data Visualization

### 🎯 Objective
The objective of this project is to analyze soil properties and nutrient levels across Karnataka districts and present the results through an easy-to-understand dashboard for comparing soil conditions and nutrient values.
